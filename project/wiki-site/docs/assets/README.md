# Figuren en afbeeldingen

Plaats hier figuren, diagrammen en screenshots voor de projectwiki. Gebruik beschrijvende bestandsnamen en voeg in de Markdown-pagina een onderschrift en alternatieve tekst toe.

Paden zijn relatief aan de Markdown-pagina. Vanaf de startpagina gebruik je bijvoorbeeld:

```markdown
![Overzicht van het project](assets/project-overview.png)

_Figuur 1. Overzicht van het project._
```

Vanaf een pagina in een submap gebruik je bijvoorbeeld `../assets/ai-flow.png`.
