# Collaboration — Project Documentation

This directory contains the team's collaboration agreements for the **Evaluating AI-generated summaries** project (Master Applied Artificial Intelligence, Block 2, 2026–2027).

## Documents

| Document | Description |
|---|---|
| [**Collab-agreement.md**](Collab-agreement.md) | Team Collaboration Agreement covering the project's purpose, team responsibilities, fair task allocation based on individual learning objectives and peer learning, work distribution, communication, meetings, deadlines, code review, conflict resolution and team sign-off. It also defines project-specific standards for evaluating AI-generated summaries, evidence-based checks, Trust / Check / Reject routing, human oversight, user testing and responsible AI use. |
